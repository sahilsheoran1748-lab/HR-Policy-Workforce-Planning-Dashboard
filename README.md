# HR Policy & Workforce Planning Dashboard

## Project Overview

This project presents an interactive HR workforce planning and governance dashboard developed from staffing information contained in an Enterprise HR Policy & Employee Handbook for 2026–2027.

The project converts the source staffing matrix into a structured dataset and analyzes current workforce levels, projected target headcount, departmental growth, and additional hiring requirements.

## Key Objectives

- Analyze current and projected workforce requirements.
- Compare current headcount with target headcount.
- Identify department-wise additional hiring requirements.
- Calculate growth percentages from the structured data.
- Present the analysis through an interactive Streamlit dashboard.

## Technology Stack

- Python
- Pandas
- Streamlit
- Plotly
- Google Colab
- GitHub

## Dashboard Features

- Workforce planning KPI cards
- Department selection
- Current vs target headcount chart
- Additional hiring requirement chart
- Department growth projection
- Interactive data table
- CSV download functionality

## Data Source

The project dataset is derived from the staffing matrix provided in the source HR policy handbook.

The source staffing matrix contains:

- Engineering & AI/ML: Current 120, Growth 35%, Target 162
- Product & Design: Current 50, Growth 20%, Target 60
- Sales & Operations: Current 80, Growth 15%, Target 92
- Total: Current 250, Source Growth Figure 25%, Target 314

The independently calculated overall growth from 250 to 314 is approximately 25.6%. The source-provided 25% figure is retained separately.

## Important Note

This project uses source-derived staffing information for analytical and educational purposes. It does not contain real employee records, personally identifiable information, or confidential employee-level data.

The project should not be interpreted as a production HR system or as evidence of actual organizational hiring outcomes.

## Future Scope

Future enhancements could include role-level workforce forecasting, automated data ingestion, scenario-based workforce planning, additional HR analytics, and integration with approved organizational data sources.
