# HR Policy & Workforce Planning Dashboard

Project Type: HR Analytics & Workforce Planning Dashboard
Source: Enterprise HR Policy & Employee Handbook 2026–2027
Technology: Python, Pandas, Streamlit, Plotly

This project converts staffing and workforce-planning information from an HR policy handbook into a structured analytics dataset and an interactive dashboard.

Key analysis:
- Current vs target workforce
- Department-wise growth projection
- Additional hiring requirements
- Workforce planning KPIs
- Interactive department-level analysis

Note:
The dataset is derived from the staffing matrix provided in the source handbook. It does not represent real employee records or confidential personal data. Calculated metrics are clearly separated from source-provided figures.
